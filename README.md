# PNUSear

부산대학교 도서관 좌석의 남은 시간을 로컬에서 확인하는 조회 전용 웹앱입니다.

새벽벌도서관 2층 `1열람실`, `새벽별당[24h]-A`, `새벽별당[24h]-B` 좌석을 대상으로 PNUL 좌석 API의 `remainingTime` 값을 가져와 좌석별 남은 시간을 보여줍니다.

## 기능

- 좌석별 상태와 남은 시간 표시
- 공식 API의 분 단위 값(`remainingTime`)과 조회 시각 표시
- 사용 중 좌석이 빈 시점부터 반납 후 25초 대기 타이머 표시
- 좌석 번호 검색
- 5초, 10초, 30초 단위 자동 새로고침
- 브라우저에서 로그인 세션 `Cookie` / `pyxis-auth-token` 저장
- 사용할 수 없는 특정 좌석 제외

이 앱은 좌석 조회만 수행합니다. 예약, 취소, 연장, 반납 요청은 보내지 않습니다.

## 남은 시간 갱신

초 단위 타이머는 공식 분 단위 값과 조회 시각으로 계산한 추정값입니다. 화면의 `조회`·`새로고침` 버튼과 자동 새로고침에는 같은 갱신 기준이 적용됩니다.

- 같은 열람실의 같은 좌석에서 공식 분 값과 사용 상태가 같으면 기존 타이머 유지
- 공식 분 값이 줄거나 늘어나면 최신 응답을 기준으로 타이머 갱신
- 사용 상태가 바뀌거나 새로 조회된 좌석이면 최신 응답 반영
- 공식 분 값이 없거나 유효하지 않으면 최신 응답의 시간 사용
- 타이머를 유지하는 동안에도 조회 시각과 공식값 표시는 최신 응답으로 갱신

브라우저 페이지를 다시 불러오면 첫 조회 결과로 타이머를 시작합니다.

## 반납 후 대기

PNUL API 응답에는 반납 시각이나 반납 대기 여부를 나타내는 필드가 없습니다. 화면은 직전 조회에서 사용 중이던 좌석이 이번 조회에서 빈 좌석으로 바뀐 경우에만 `반납 후 대기` 상태와 25초 카운트다운을 표시합니다.

- 사용 중 → 사용 가능 전환을 확인한 시점부터 `25초 후 사용 가능 예상` 표시
- 25초 경과 후 추가 조회 없이 `사용 가능` 표시
- 처음 조회한 빈 좌석과 페이지를 다시 불러온 뒤의 빈 좌석은 바로 `사용 가능` 표시
- 대기 중 다시 조회해도 대기 타이머 유지
- 대기 중 다른 사용자가 좌석을 사용하면 사용 중 상태와 새 남은 시간으로 전환
- 조회 실패 시 마지막으로 확인한 좌석과 타이머 유지, 조회 실패 메시지 표시

반납 시각은 다음 조회에서 확인합니다. 따라서 대기 종료 표시는 실제보다 최대 자동 새로고침 간격만큼 늦을 수 있습니다. 비활성 좌석이나 사용이 제한된 좌석은 `사용 불가`로 표시합니다.

관련 API 필드는 [PNUL 좌석 API 참고 문서](docs/pnul-api.md#좌석-상태-필드)를 확인하십시오.

## 좌석 검색

`좌석별 남은 시간` 패널의 `좌석 검색` 입력창에 좌석 번호를 입력하면 해당 좌석만 표시합니다. 좌석 수 표시는 `검색 결과 수/전체 좌석 수` 형식으로 바뀝니다.

- 쉼표나 공백으로 여러 좌석 입력 가능 (예: `13, 120`)
- 앞자리 0 무시 (`13`과 `013`은 같은 좌석)
- 조회 대상 열람실 전체에서 같은 번호의 좌석 표시
- 숫자가 아닌 입력은 무시
- 입력값은 저장하지 않음, 페이지를 다시 불러오면 초기화

## 실행

Node.js 18 이상이 필요합니다.

```bash
npm start
```

설치할 패키지는 없습니다. 서버는 `private/`의 세션 파일을 자동으로 읽습니다. 세션은 화면에서 저장한 직후 서버 재시작 없이 반영됩니다.

실제 API 없이 화면만 확인하려면 `npm run mock`을 실행하십시오.

브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:4173
```

## 로그인 세션 저장

PNUL 좌석 상세 API는 로그인 세션이 있어야 조회됩니다.

1. 공식 부산대 도서관 좌석 페이지에서 로그인합니다.
2. DevTools Network에서 `api/rooms/{roomId}/seats` 요청을 엽니다.
3. Request Headers 전체 또는 `Copy as cURL` 내용을 복사합니다.
4. PNUSear 화면의 `로그인 세션` 입력창에 붙여넣고 `세션 저장`을 누릅니다.

저장된 파일:

```text
private/pnul-cookie.txt
private/pnul-auth-token.txt
```

`private/`는 `.gitignore`에 포함되어 있어 커밋되지 않습니다. 서버는 `/private/` 경로 요청에 403을 응답합니다.

## CLI로 세션 저장

브라우저 대신 파일로 저장하려면 Headers 내용을 `private/pnul-headers.txt`에 넣고 실행합니다.

```bash
npm run import-headers -- private/pnul-headers.txt
```

## API

```http
GET /api/status
GET /api/seats?rooms=새벽벌도서관 2층 1열람실,새벽별당
POST /api/import-headers
```

`POST /api/import-headers`는 로컬 `private/` 파일에 인증 정보를 저장하기 위한 엔드포인트입니다.

## 확인용 Probe

PNUL API 연결 상태를 터미널에서 직접 확인할 수 있습니다.

```bash
npm run probe
```

## 동작 검사

타이머 갱신, 반납 대기, 좌석 상태 변환, 좌석 검색의 회귀 검사는 다음 명령으로 실행하십시오. 실제 PNUL API 연결이나 로그인 세션 없이 실행할 수 있습니다.

```bash
npm test
```

## 환경 변수

| 변수 | 기본값 | 용도 |
| --- | --- | --- |
| `PORT` | `4173` | 서버 포트 |
| `HOST` | `127.0.0.1` | 서버 바인딩 주소 |
| `PNUSEAR_PROVIDER` | 실제 조회 | `mock` 지정 시 가짜 데이터 사용 |
| `PNUL_COOKIE_FILE` | `private/pnul-cookie.txt` | Cookie 파일 경로 |
| `PNUL_AUTH_TOKEN_FILE` | `private/pnul-auth-token.txt` | 인증 토큰 파일 경로 |
